# テクテク ポップアート ジェネレーター

テクテクをアンディ・ウォーホル風のカラーパネルで再着色するポスター生成ツール。  
ウォーホルの代表作と葛飾北斎の代表作からカラーパレットを抽出し、洋風×和風のポップアートを生成します。

![TEKUTEKU POP ART](tekuteku_2x2_hokusai_20260409_161929)

---

## 使い方

```bash
# 4×3 全パレットポスター（デフォルト）
python warhol_tekuteku.py

# 2×2 洋風（ウォーホル）ランダム
python warhol_tekuteku.py --mode warhol

# 2×2 和風（北斎）ランダム
python warhol_tekuteku.py --mode hokusai

# 2×2 洋風2枚＋和風2枚 ランダムミックス
python warhol_tekuteku.py --mode mix

# 入力画像・出力先を指定
python warhol_tekuteku.py --mode warhol -i my_character.png -o output/
```

### オプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `--mode` | `full` / `warhol` / `hokusai` / `mix` | `full` |
| `-i`, `--input` | 入力画像パス | `tekuteku.png` |
| `-o`, `--output` | 出力ディレクトリ | `.`（カレント） |

2×2モードは実行するたびにランダムで組み合わせが変わります。

## 仕組み

1. **マスク抽出**: テクテク画像（白背景＋水色ライン）から、白との距離でライン強度マスクを生成
2. **内部領域検出**: ラインを閾値化し、四隅からフラッドフィルして外側を検出 → 反転で内部領域を取得
3. **再着色**: 背景色 → 内部をfill色 → ラインをline色の順にコンポジット

アンチエイリアスを連続値マスクで処理しているため、色の境界が滑らかに仕上がります。

## カスタマイズ

スクリプト冒頭の `WARHOL_PALETTES` / `HOKUSAI_PALETTES` を編集すれば、パレットの追加・変更が可能です。各パレットは3色で構成されています：

```python
("パレット名", {
    "bg":   (R, G, B),   # 背景色
    "line": (R, G, B),   # ライン色
    "fill": (R, G, B),   # 内部塗り色
})
```

入力画像を差し替える場合は、白背景＋単色ラインの構成であれば同じ仕組みで動作します。
